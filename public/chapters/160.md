# 第160章 阶段结束

阿秀在平板上画了一条时间轴，把过去十二个小时内发生的关键事件按顺序标注上去。她的手指在屏幕上划拉的时候很稳——一个在战火中操作过无人机、校准过激光制导、用蜂鸣声频率反推过炸药倒计时的技术员，画时间轴对她来说像呼吸一样容易。但画完回看了一遍，她的手指在屏幕上方悬停了大约五秒——不是忘记了什么，是发现这条时间轴上的每一个节点，都离"全军覆没"只差毫厘。

00:00——凌晨，沈迷潜入酒楼，在原初通道上布置总锚点。00:43——沈迷在酒楼各楼层布设二十三根精神触须，完成幻术网覆盖。01:15——沈迷在招待所提前安装窃听器和针孔摄像头，选好防弹门爆破位置。02:30——李云和小雪跨界猎狰，同时沈迷在防弹门上贴好高爆破甲炸药，启动倒计时。02:38——李云用重狙击落灌灌鸟。02:41——李云取灌灌鸟脑髓和心脏。02:43——李云在招待所卧室用五粮液急炖灌灌破幻高汤。02:45——全员喝下高汤，破妄之眼Buff激活。02:46——炸药引爆，防弹门炸开。02:46——孤狼割断沈迷手筋。02:47——沈迷被俘。02:48——小雪拆除沈迷脑内三根精神控制引线。03:00——全员撤离进地下储藏室。03:05——沈凡——前代号幻瞳——开口交代那个组织的情报。03:10——红叶开始破解沈凡鞋底军用终端。

"十二个小时。"阿秀把时间轴投在墙壁上——用她那台小型LED投影仪，画面在储藏室发霉的白墙上呈现出一种褪色的蓝。她站起来，指着时间轴最右侧那一大块空白区域——从此刻到今晚午夜，大约还有二十个小时。"这二十个小时是我们唯一的窗口。雷虎的百人佣兵团会在午夜到达——意味着我们必须在午夜之前完成至少四件事。第一，红叶完全破解玄武-7协议，截获战情同步数据。第二，根据数据制定防御或撤离计划。第三——无论计划是什么——找到足够的火力。我们现有的武器：一把反器材重狙，十几颗穿甲弹，一把短刀，一把占生刀，一根铁箍棍，还有一只会吐火的雏鸟。怼百人和RPG打——不够。"

"第四件事。"李云站起来，走到墙壁上投射的时间轴前面。他用手指点了一下那块空白区域的正中央——"我要再跨一次界。狰肉的效果我们验证过了——吃完之后爆发力极强，但狰肉能给的只是短时间的狂暴，挡不住子弹。我们需要一样东西——能让我们在绝对火力劣势下还有一战之力的东西。古籍里一定有。"

小雪从坐着的行李架上站起来，走到李云旁边。她没有说话——她低着头看着自己的手。那双手上还残留着狰的血迹——干涸的、发黑的血，嵌在指甲缝和关节褶皱里。狰的血腥味已经散得很淡了，但她知道自己不需要开口说话——她知道李云在想什么。猎狰的时候他们用的是狙击枪、炸药和锅巴的阳火——三样东西加起来才把狰打死。现在要找一只比狰更强的异兽——一只在古籍批注里被标注为"肉极烈、食之可得嗜血狂暴之勇"的异兽——还要在二十小时内跨界猎杀、带回、烹饪、吃完、等Buff生效。这个时间表比今天凌晨急炖灌灌高汤的八分钟时间表长得多——但风险也高得多。灌灌鸟虽然精神攻击强，但物理防御极弱——一发穿甲弹就能打穿翅膀。狰是重型物理系——他们差点翻车。而如果古籍里下一只异兽的物理破坏力比狰还强——他们靠什么猎？

"先不急——我们还没到决定猎什么的时候。"李云转过身，看着红叶。红叶正在用热风拆焊台把沈凡鞋底终端的主控芯片从电路板上吹下来——热风枪的温度设定在三百五十度，焊锡在高温下融化成了银亮的液体，芯片周围的松香助焊剂发出微微的焦香。她的手稳得像外科医生——一个二十四岁的黑客能在不到两厘米高的芯片引脚之间操作焊枪而不碰到任何一根走线，这样的手稳程度甚至超过了赵铁山教出来的古武学员。

"红叶——你的进度？"

"芯片拆下来了。EMMC闪存——三十二GB，球栅阵列封装。"红叶用绝缘镊子夹起那枚比指甲盖还小的黑色芯片，放在逻辑分析仪的测试座上。测试座的探针自动对位——三十二根比头发丝还细的铜钨合金探针精准地压在芯片底部每一个球栅的接触点上。逻辑分析仪的屏幕上开始滚动出十六进制数据流——密密麻麻的、每秒几千行的数字和字母在屏幕上飞过。"芯片没有触发自毁——那个组织的自毁监测程序监控的是螺丝孔的通电状态。只要不碰螺丝，芯片就不会熔。现在——开始破解文件系统。"

红叶启动了破解脚本——不是常规的暴力破解，是她自己写的、专门针对那个组织KR系列军用终端文件系统弱点的一套注入程序。程序的核心原理利用了KR-8固件里一个古老的、从未被修复过的漏洞——在开机自检过程中，EMMC闪存的主引导记录在加载加密文件系统之前会有大约零点三秒的明文窗口。在那零点三秒里，系统会以明文方式读取存储分区表，确认加密分区的起始地址和大小。如果能在这个窗口内注入一段伪造的分区表指令，整个加密分区就会被系统当作"未加密的空白区"挂载——所有数据明码可见。

"零点三秒——太短了。"阿秀看着红叶的屏幕，"你不可能手动抓这个窗口。"

"不手动。硬件中断——我在逻辑分析仪上设置了一个触发条件：只要检测到主引导记录的读取总线信号，就自动在十毫秒内注入伪造分区表。比手动快三十倍。"红叶敲下回车键。逻辑分析仪上的指示灯开始频繁闪烁——不是乱闪，是按着某种固定频率在闪烁，像心跳。然后屏幕正中间弹出来一个窗口——"PARTITION TABLE INJECTED. FILESYSTEM MOUNTED AS UNCLEARED."

文件系统成功挂载。

红叶的手指在键盘上敲得飞快——她在找战情同步的缓存目录。玄武-7协议的战情同步数据在接收完成后会临时存储在终端的一个隐藏分区里——路径是/sys/ops/cache/tsync/，用KR-8的默认文件管理器看不到，但用Linux内核的命令行可以直接访问。她敲了一条简单的bash命令——ls -la /mnt/uncrypted/sys/ops/cache/tsync/——然后屏幕上一个隐藏文件夹显现了出来。

文件夹里只有两个文件，一个是sync_cache.db——加密的SQLite数据库文件，存储了所有历史战情同步记录的加密摘要。另一个——sync_active.tmp——当前正在写入的战情同步缓存，未加密（因为在本地缓存时不需要加密，加密只发生在卫星传输阶段）。文件大小：正在增长。从0.3MB长到0.8MB，再到1.2MB——说明那个组织的指挥中心正在向某台终端执行实时战情同步！

"这不是沈凡的终端在接收——他的终端处于离线状态已经超过半小时了。这是雷虎的终端——那个组织正在对雷虎进行战情同步！"红叶的声音变得又轻又急——像是怕惊吓到屏幕上正在增长的那个.tmp文件。她把sync_active.tmp复制到主机桌面上，双击打开——一份完整的、未加密的、正在实时更新的作战计划，展开在她的屏幕上。

满屋的人围了过来。

屏幕上出现了第一行字符——"OPERATION IRON HAMMER - TACTICAL DEPLOYMENT SYNC / TARGET CODE: SHANHAI RESTAURANT ANCHOR / EXECUTOR: LEI HU TIGER FANG PMC / FORCE COMPOSITION: 100 / WINDOW: TODAY 00:00-04:00."

然后是一整页的兵力部署图。A队——正面突击，十六人，从酒楼正门攻入，配备四挺M249轻机枪和六具RPG-7火箭筒。B队——侧翼包抄，二十人，从酒楼后巷通过防火梯上三楼，配备HK416突击步枪和夜视仪。C队——外围封锁，三十人，分散在酒楼周边六个制高点，用狙击枪和轻机枪封锁所有逃生通道。D队——机动预备，三十四人加雷虎本人，三辆改装皮卡配置了德什卡重机枪，部署在两个街区外的货运停车场待命，随时向任何方向增援。

"全体到齐。"赵铁山看着屏幕上那张兵力部署图，手指在上面画了一条线——从酒楼正门到后巷防火梯。"雷虎不是只会火力烧——他是真会用兵。A队正面佯攻，B队侧面包抄，C队封锁退路，D队机动补位。一旦A队把我们的火力吸引到正门，B队就能在三分钟内爬完防火梯，从三楼绕到我们背后。我们的后背对着后巷——他只需要在合适的时间出现在合适的位置。"

"前提是——他不知道我们能看到他的计划。"李云指着屏幕上的战情同步数据——数据的最底部有一行细小的代码注释：//REALTIME BIO: LEI HU HR=68 INDUCTION TIME: 21:37。意思是雷虎本人的实时心率是每分钟六十八次，数据感应时间——晚上九点三十七分。

"他现在在什么位置？"

红叶手指飞快地操作——她把战情同步数据里的GPS坐标调出来，输入到阿秀的卫星地图软件上。地图放大——一个红点出现在金三角湄公河畔的一座废弃橡胶加工厂里。和赵铁山十年前那场战斗的坐标，误差不到五百米。

"雷虎还在金三角。但战情同步的数据里有一行行军计划——他用三架改装过的运输直升机运送先头部队，油料点标注在距酒楼约八十公里外的一处私人机场。以运输直升机的巡航速度——大约三小时航程。也就是说他最早到达时间——午夜零点。他不见得——但他下属的先进侦察小组会在今晚十点前后到达目标区域附近进行现场侦察。你们必须在侦察组到达之前离开招待所。如果被他们先锁定了招待所作为防御据点——百人火力会把这个地方连地基一起掀掉。"

李云看了一眼阿秀时间轴上的倒计时——十八个小时。十八小时后，雷虎的百人重火力佣兵团会把山海酒楼和招待所一起夷为平地。

"阶段二——'归途暗影与战术初猎'——现在正式结束。"李云在阿秀的时间轴顶上加了一个红色的"Phase II END"标签，然后手指划到时间轴的起点，在"Phase III"的空白区域里写下两个字——

"猎狰升级版。"
