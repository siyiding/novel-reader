# 第166章 火力焦虑

李云把所有人都带进了酒楼后厨。走廊里的脚步声很轻，每个人都在刻意压低声响，像一群猎人在接近猎场前最后的静默行军。

后厨是他最熟悉的地方。黑暗中没有开灯——为了防止侦察组的夜视仪捕捉到光线，红叶用胶布把后厨所有窗户的缝隙都封了，只留了一个通风口的百叶窗斜开着透气。黑暗中，李云摸到了他用了三个月的那把主厨刀——刀刃上还残留着最后一次使用之后没洗干净的狰肉油脂，摸上去滑滑的，带着狰肉特有的一种说不出的辛烈气味。他用围裙擦干净刀身——那把黑围裙挂在炉灶旁边的挂钩上，三个月来洗了无数次，布料已经洗得发白起毛，被蒸汽和油烟熏透了的味道洗不掉——那是山海酒楼倒闭前的最后一波食客留下的气息：花椒、辣椒、郫县豆瓣、被滚油泼过的蒜末、熬了五个小时的猪骨高汤、清蒸石斑鱼浇上去的滚烫豉油。李云的鼻子在黑暗中把这些气味一层一层地拆出来，他闭着眼睛也能说出这道菜用了二荆条还是小米辣——但是今天他不开灶。他来这里不是为了做菜。他是来算账的。

"四挺M249轻机枪——每挺每分钟理论射速七百五十发。六具RPG-7——每具携带备弹两枚，共十八枚火箭弹。三把德什卡重机枪——配置在三辆改装甲皮卡上，每把每分钟理论射速六百发。一百人——每人标配HK416突击步枪一把，四个弹匣，一百六十发子弹。加上手枪、手雷、闪光弹、烟雾弹、破片手雷。保守估计——他们带来的总弹药量超过五万发。"阿秀把从战情同步数据里提取出来的虎牙佣兵团装备清单投在厨房不锈钢操作台的背面——那块不锈钢板在投影仪的冷光下反射出微微发蓝的数字和字母，让整张装备清单看起来像一份不祥的体检报告。

"五万发。"赵铁山用手指在操作台上比了一个大拇指和无名指张开的距离——大约二十厘米。他的手指粗糙得像老树皮，指节上的茧子在黑暗中泛着微光。"一发M249的子弹从这个距离打进你肚子里——不是打穿，是炸开。子弹进入人体之后会因为阻力急减速发生翻滚——翻滚的弹头把你腹腔里所有能撕开的东西都撕成碎片。等你倒在地上——十秒，最多十五秒——就没了。"他说这话的时候语气平静得像在讲一道菜的火候，但后厨里所有人都安静了下来，连呼吸声都放轻了。

"正面交战的话——我们所有人都是十秒钟。"孤狼的语气依然是那种不温不火的计算腔，但他的破妄之眼在黑暗中眨得比平时快了一点点。他习惯的战场是黑夜、窄巷、冷兵器一对一——正面阵地战、被重火力覆盖、四面八方都是子弹——这不是他的领域。不是他怕，是他够诚实。在绝对火力差距面前，任何战斗经验和技巧都会被压缩到一个极其狭窄的生存窗口里——在三挺机枪组成的交叉火力网中你能活多久不是取决于你有多快——是取决于机枪手的手有多稳。他看过的覆灭案例太多——特种部队夜袭敌方哨站，刚好碰上巡逻犬，狗一叫机枪手一压扳机，再厉害的突击手也跑不过子弹。

"所以——不能正面交战。"李云从围裙兜里把老李那本《山海异兽美食录》拿出来，翻到画着狰的那一页。他把书摊在不锈钢操作台上，用主厨刀压住书页边角。阿秀把投影仪的焦距调到那一页上——狰的素描被放大了，赤红色的蓬松皮毛、五条如鞭的尾巴、额上那根粗壮的黑色独角、以及肩胛根部被老李用箭头反复标注的那块极烈之肉，在放大后每一个细节都清晰得让人心跳加速。

"老李在这页画的——就是狰。狰在《西山经》章莪之山——我们上次在玉山猎过，吃了后腿肉。但这次不一样——老李的批注指向了狰的肩胛根部，那块肉藏着嗜血狂暴的效果。上次我们吃错了部位——后腿肉的力量增幅只有七成，肩胛根部的肉才是真正的'极烈'之肉。老李在批注里特别标注了一个箭头——指向狰前肢基部的肩胛位置，旁边写着'此肉最烈，非烈酒浸透不可食'。他不是在描述另一种异兽——他是在同一只狰的身上标注了不同部位的肉质功效差异。狰的眼睛是金色的，可以直视——这点我们已经验证过了，上次猎狰的时候我和小雪盯着它的眼睛看了不下十秒，没有任何精神攻击。狰不是精神系异兽——它的危险全部来自物理层面：五条尾巴的抽击、独角的撞击、以及——它的肉。它的肉本身就是最危险的武器。"

"所以猎它——和上次一样，我和小雪去。你负责听觉警戒，我开枪——跟上次猎狰的战术一样。狰的弱点是——它的听觉覆盖范围虽然广，但它的移动速度受限于地形。玉山的碎石坡是我们上次成功的关键——狰体型大，碎石的滑塌会让它失去平衡。这次我们要找一个类似的地形——有碎石坡或者松动岩层的山坡。不需要看它的眼睛——狰的眼睛本身没有精神攻击力，但它在冲锋时会锁定目标，瞪住你的眼睛是为了判断你的逃跑方向。"

小雪想了想——把占生刀在手上转了个半弧，刀背贴着前臂，冰凉的金属触感让她微微眯了一下眼。"和上次猎狰不同——这次我们要取的是肩胛肉，不是整只狰。狰的肩胛根部在它前腿向前迈步时会短暂暴露——那是一个大约两掌宽的三角区。瞄准这个三角区——重狙穿甲弹可以从侧面打进去，穿透肩胛骨外侧的薄层后直接撕裂肌肉附着的肌腱。不是打死它——是废它一条前腿。残了一条前腿的狰跑不快，我们可以用陷坑和霰弹枪近距离收割。但前提是——地形必须有天然的隘口或者碎石坡，把它逼到没法全速冲刺的地方。"她说完顿了一下，补充道，"还有一点——上次猎狰的时候它的五条尾巴是交替抽击的，频率大约每秒两到三次。残了一条前腿之后它的重心会偏移，尾巴的抽击精度会下降至少四成。这就是我们收割的窗口。"

李云点头——这和他脑子里想的战术一致。小雪是巫女——部落里最重要的猎队辅助，她的听风术能在狰进入碎石坡范围之前就精确锁定它的位置和移动方向。

"时间。如果现在出发——最快也得六小时来回往返。加上料理——从扒皮到取肉到炙烤——参照狰那次最少也要两个半小时。出发前还需要准备现代装备——狙枪的一把不够，我们需要近距火力。赵叔——你储物柜里还有把M870霰弹枪——没记错的话，弹仓还有十五发鹿弹。够打破它头骨那类厚皮。对狰之前的近距C4陷坑也能用——但我们需要更多炸药——招待所走廊上沈迷留下的那些未引爆的背板炸药还剩好几个——我去卸下来。"

"我去。"孤狼站起来——他不会做菜，不会看古籍，不会破解终端——但他在走廊上观察过每一块炸药的贴片状态和引爆引信的连接方式。他爆破知识比李云高一个量级。在招待所走廊天花板上他趴过——没人知道他天花板冷压时间不只是为了伏击沈迷，也是顺便把沈迷没来得及引爆的背板和震慑炸药都顺手记下了几个活跃路线。"一共还剩五块C4破障板——原南边水泥——每板含五十克每个三硝基甲苯多名民团惯用配比速叠工具。凑凑我可以做两块——大小方块——摸两个远程起爆器放耳麦同步引爆。"

"装备清单——阿秀，你来统领——去。"李云的声音在后厨的黑暗里显得格外沉，像一块石头丢进了深井。

阿秀转身带着红叶爬上三楼储藏间拿出全队所有的武器储备清列：反器材重狙一把（配四发穿甲弹、三发穿甲燃烧弹）；占生刀一把；短刀一把；铁箍棍一根；铁指环一副；烟雾弹五枚（由改装闪光弹壳体充烟剂而成）；六具无线引爆装置的C4炸药。

全部加起来还不到一只百人佣兵装备总量的一小部分。阿秀把清单在屏幕上排列整齐，每一行武器后面都标注了弹药数量和状态——穿甲弹四发、穿甲燃烧弹三发、鹿弹十五发、烟雾弹五枚、C4六具。数字冷冰冰的，像是一份自知不够的遗书。但猎狰不是打佣兵——不需要把他们全打死。能打死那只异兽就可以了。李云把清单关掉，在黑暗中站起身来，后厨里只有通风口灌进来的夜风发出低沉的呜咽声。
