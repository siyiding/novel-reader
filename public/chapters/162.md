# 第162章 红衣破译

红叶的工作台已经从那张缺了腿的旧桌子扩展到了储藏室半个地板。她的装备在地面上铺开了——热风拆焊台、逻辑分析仪、三台备用笔记本电脑、一个便携式示波器、两排密密麻麻排列在防静电泡沫垫上的备用芯片、一卷锡线、一把烙铁、四盒不同规格的绝缘镊子、五根USB-C转接线、一块备用电池。这些设备在普通人看来像一堆毫无逻辑的电子垃圾，但在红叶眼里是一张精心编织的捕鱼网——每一条线、每一个触点、每一块芯片的位置都是经过了精密计算之后的决策。

沈凡的KR-8军用终端已经被她拆成了十二个独立零件——主控芯片（已挂载在逻辑分析仪上）、EMMC闪存芯片、基带芯片、WIFI模块、蓝牙模块、卫星通信模块、电源管理芯片、GPS天线、加密协处理器、震动传感器、温控芯片、备用电池。她把它们整整齐齐地排成两行，像法医在解剖台上排列从一具尸体里取出的器官。

"玄武-7协议的核心——不在主控芯片上，在加密协处理器里。"红叶用绝缘镊子夹起那枚比米粒还小的加密协处理器——博通公司的定制版安全芯片，型号被激光蚀刻机磨掉了，但从引脚布局能反推出是博通BCM-589x系列的军用变体。"那个组织的安全设计很狡猾——他们把加密引擎从主控芯片上剥离出来，放在一颗独立的协处理器里。即使黑客拿到了主控芯片的全部权-限，加密引擎依旧在协处理器里独立运行——相当于你的电脑操作受到影响，但保险柜的密码锁还在自己转自己的。"

"那你怎么破？"李云蹲在她旁边，看着逻辑分析仪屏幕上那些飞流而下的十六进制数字。他对编程几乎一窍不通，但他懂一个道理——任何系统的破解归根结底都是在找一个"不需要密码就能进门"的漏洞。

"协处理器的漏洞在于——它自己也需要从闪存里引导固件。"红叶把一片极薄的柔性连接器贴在加密协处理器底部的四根测试点上——那四根测试点是协处理器在产线测试时用来烧录固件的调试接口，在出厂后应该被物理熔断的。但那个组织的硬件供应商为了降低成本，用的是软件熔断——"软件熔断"意思是通过一个一次性编程位把调试接口禁用，但不禁用物理通路。如果在协处理器上电自检的那一毫秒窗口内，用一个极短的电压脉冲把那个编程位倒回未熔断状态——调试接口就重新开放了。

"我需要制造一个精确到微秒级的电压脉冲。这个脉冲的时间窗口——协处理器从晶振起振到引导固件加载——大概是一百二十微秒。必须在这一百二十微秒之内把一点八伏的编程电压打到第三号测试点上——早一秒打不进去，晚一秒芯片就锁死了。"

她说着，从工具箱里翻出一块她自制的"脉冲注入器"——其实就是一个改装过的单片机开发板，上面焊了一个高速MOSFEt开关和几个精密的电容。她在笔记本电脑上敲了几行Arduino代码，设定了脉冲宽度——一百一十五微秒，比窗口稍微短五微秒作为安全余量。然后把脉冲注入器的输出端接到协处理器的第三号测试点上。

"倒数——三、二、一。"她按下回车键——脉冲注入器的红色LED闪了一下。逻辑分析仪的屏幕上刷出来一整段新的启动日志——和刚才的日志完全不同。刚才的启动日志只显示"COPROCESSOR: SECURE BOOT - DEBUG DISABLED"。现在的启动日志变成了一段密密麻麻的寄存器转储——每一行都是协处理器内部寄存器的实时状态。

"调试模式开启了。"

红叶的手指在键盘上跳得飞快——她在用调试接口向协处理器的指令寄存器里注入自定义汇编指令。指令分三步——第一步：绕过身份验证。第二步：把加密引擎的会话密钥（Session Key）写入一个未加密的共享内存区。第三步：触发一次"伪装的"战情同步请求——让主控芯片和协处理器之间重新建立加密会话。三步行云流水——从输入第一行汇编指令到截获会话密钥，不到两分钟。

"这就是玄武-7的命根子。"红叶指着屏幕上一行十六进制数字——256位的会话密钥。"有了这个密钥，我可以逆向解密所有历史战情同步数据——包括那个组织指挥中心和雷虎之间过去三个月的所有通讯记录。"

阿秀推了推眼镜，把笔记本电脑拉到自己面前。她打开数据库软件，把红叶截获的会话密钥输入进去，然后对sync_cache.db文件执行了一次全表解密。解密的进度条从零跳到一百用了不到三秒——3GB的加密数据库，在会话密钥的加持下瞬间变成了明码。屏幕上弹出了那个组织过去三个月的所有战情同步记录——按照时间线排列，最新的一条在三分钟前刚刚更新。

"这台终端——不是沈凡的。是雷虎的。或者至少是雷虎指挥链中某一个人携带的终端——因为从战情同步数据来看，这台终端一直跟着虎牙佣兵团的核心指挥层在移动。"阿秀把数据库里的GPS坐标轨迹可视化——一条红色的轨迹从金三角的橡胶加工厂一直延伸到中老边境，然后在中国境内拐了几个弯，最后停在一个坐标上——距酒楼直线距离约八十公里的一处废弃军用机场。"这个机场应该是他们的中转点。虎牙佣兵团的主力在今天下午三点已经到达了这个机场——现在正在进行最后的装备检查和战前简报。"

"战前简报的内容——能截获吗？"

阿秀在数据库里找到了最新的战情同步数据——三分钟前刚刚同步过来的。数据类型标注是"MISSION BRIEFING DELTA - FINAL"，文件名是"iron_hammer_delta_brief.pdf"。她双击打开文件——加密已经自动解密了，屏幕上展开了一份完整的作战计划PPT。

一共三十二页。第一页是任务代号和行动目标——"铁锤清理·第四次修正版"。第二页是目标建筑结构图——山海酒楼的完整内部结构，精确到每一堵承重墙的位置、每一个楼梯间的宽度、每一个窗户的朝向。第十八页是兵力进攻路线——A队从正门正面突击，B队从防火梯突入三层，C队在周围建筑制高点设狙击位。第二十五页——火力压制方案——写着"在A队与B队形成交叉夹击态势后，如遭遇顽固抵抗，授权使用RPG-7对目标建筑进行外部结构定向爆破，将整栋建筑在四百秒内逐层压塌。"第三十页——"夺取空间异常点后转移流程"——"利用D队改装甲皮卡封锁原初通道所在建筑，就地建立控制区。"

"他们不是来'攻占'酒楼的。他们是来'拆'酒楼的。"李云看着屏幕上的作战计划，手指点着第十八页上B队的路线——防火梯。那条防火梯在装修时被赵铁山用钢筋和水泥堵过——但没有完全堵死，只堵了一半。如果B队的爆破专家碎骨在防火梯底部定向爆破，防火梯会在半分钟内全部打通，B队二十人全副武装直接上到三楼——从背后发起攻击。"我们原来的假设是他们从正面强攻——但这个部署图——雷虎已经把我们可能会设防的可能性全部考虑进去了。他知道我们会猜到正面是最可能的进攻点，所以他用正面佯攻，真正打进来的在侧翼——我们在防火梯那边。"

"还不够。"红叶把作战计划翻到最后一页——第三十二页。那页上只有一个嵌套加密的超链接，标注是"DIRECTOR OVERRIDE - AUTHORIZATION CODE: THUNDER-7"。她尝试用会话密钥解密——无效。不是玄武-7协议加密的。是一个更高级别的独立加密——那个组织总部的"导演权限"（Director Override），只有那个组织的最高决策层才能发布。"这个加密层级比玄武-7高两级——我需要更多时间才能破解。但超链接的元数据显示文件类型是'live_stream_config'——直播流配置。也就是说那个组织总部打算通过雷虎身上某个实时摄像设备——直播这场袭击。他们不是为了'执行任务'而派雷虎来的。他们是要用人——用法——用这场袭击本身——来验证什么超过夺取空间异常点之外的终极目的。"

所有人都沉默了。红叶的手放在键盘上——她的手指还在微微发抖，不是因为冷，是因为愤怒。愤怒的源头不是说恐惧——而是一个黑客在看到比自己更高级更精密但也更邪恶的系统的第一反应：必须拆了它。

"雷虎身上的直播流配置——什么时候能破解？"

"如果给我六个小时——也许。"红叶推了推眼镜，"但如果他们在午夜发动攻击——我们只有不到九个小时。破解不了直播配置，但能做的事不是没有——既然我能解密他们的战情同步数据，我就能往里面写点什么，比如一个——假的命令。"
