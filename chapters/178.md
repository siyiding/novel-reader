# 第178章 炭烤狰肉排

李云把第六块肉排从烤架上夹起来的时候，窗外的机枪声还在继续。M249弹链在装甲板上炸开的声响隔着两层水泥楼板传进地下室，被墙体过滤成了沉闷的、像是用手指关节猛敲一扇厚实木门的咚咚声。他把肉排搁进最后一个不锈钢餐盘，关掉炭火炉膛的风门。梨木炭在关闭进风口后不再咆哮——那些白灰覆盖的炭块在缺氧状态下缓缓地暗下去，从明亮的橙金色变成暗红，再从暗红变成一种残余的、像是没醒透的暗鸽子血。炉膛里最后一丝明火灭了。

六块炭烤狰肉排——全部完成。

公狰的三块肉排，焦壳颜色偏深褐，切开后截面肌理呈现出一种极其清晰的放射状纹理，脂肪层熔化后填充在肌束之间，让每一根纤维都裹着一层半透明的琥珀色脂膜。母狰的三块肉排，焦壳颜色稍浅，偏向深金褐色，切面的肌理比公狰更细、更密——密到用肉眼看几乎分辨不出单独的纤维纹路，整块切面在灯光下看上去像一块被打磨到镜面光泽的深红色玉石。

他把餐盘推到每个人的位置前。

"趁后熟阶段吃——再过三分钟焦壳会变软，肉汁开始往外渗，灵能流失就会增速。"李云说着已经拿起了自己的筷子。他的那块是公狰左后腿的第二块——脂肪含量中等偏上，肉质处于刚过"绷紧和松弛之间"的最佳临界点。离炉的时间刚好超过三分钟——焦壳还脆，肉汁正在后熟的最高峰——此刻是吃入口的最佳时刻。

赵铁山第一个低下头。

他把筷子换成刀。老赵吃饭不用筷子切肉——他用刀把整块肉排横切成三条宽约两指的肉条，然后用手直接拈起中段那条最宽的塞进嘴里。他的咬合力不依赖牙齿——在古武的训练体系里，咬肌和颞肌是"上盘劲"的根基，练了四十多年的古武者，牙关咬合的力量能把一颗核桃连壳咬碎。他的牙切进狰肉焦壳的时候，整个地下室都听见了那记极清脆的"咔嚓"——像用姆指弹碎了初冬河面第一层薄冰。

焦壳在他的臼齿间碎裂成极细的碎片，那些碎片不是粉末状——是极小的、边缘锋利的脆片，在舌面上像被扬天的细碎玻璃。然后肉汁涌出来了——公狰后腿脂肪层丰厚的优势在这一刻体现得淋漓尽致。液态的高温脂质顺着牙缝渗进舌根两侧的味蕾区——那不是普通的肉油，狰脂肪里的铁元素在炭火烤制过程中已经氧化成了二价铁离子，和脂质结合后生成了一种只有高温下才会出现的"铁香"。铁香在舌头上的感觉不同于任何普通调味料——它不咸不甜不酸不辣，它是一种从口腔直接击打鼻腔后方嗅上皮组织的强烈的冲锋——三叉神经和嗅觉神经在同一点被刺激到了。赵铁山感觉自己的眼眶被冲了一下——不是眼泪，是鼻腔里瞬间涌入的一股灼热感，让他不得不大口换了口气，把那口带着铁香的热气压进肺里。然后他开始咀嚼——狰肉不比牛肉，狰肉纤维之间几乎没有筋，但纤维本身的密度是牛肉的两倍以上。正常人的咀嚼肌嚼三口就会酸。但赵铁山嚼了七口——每一口都像在咬一块被炖得将烂未烂的牛腱——越嚼肉汁越多，越嚼纤维越碎，越嚼铁香越浓。嚼到最后一口，他把碎肉往舌根一推，喉结一滑——整口肉下去了。然后他感觉到了一件事——胃在扩张。不是吃撑了——是在为即将到来的爆发性输出做储备。狰血素刺激胃壁平滑肌扩张，胃容量在几秒之内增加了一倍——这意味着身体的血液正在从消化系统被调往四肢，胃里只留下一层薄薄的高浓度能量液。那种感觉非常奇怪——你明明刚吃了一块一斤重的肉排，但肚子立刻又饿了。不是真的饿——是身体在急需更多能量。

"再一块。"赵铁山从自己的餐盘里拈起最后一条肉条，不嚼了——直接吞。他把肉条整块吞下去的时候喉结上下一滑——肉条在食道里还在发热。

孤狼吃第二块的时候换了个姿势。他原本坐在那张破沙发上——屁股刚沾着沙发的弹簧就弹起来了。不是坐不住——是狰血素让他的下肢肌腱处于一种既松弛又绷紧的奇怪的"预备蹬力态"，坐着的姿势会让他的跟腱和腓肠肌感到一种压抑的不适感，好像两条腿在同时对他说"站起来"。他站起来之后肘靠在墙面上，站着把第二块肉排切成了小块——但这次他强迫自己停下来，开始慢慢地嚼。

这是小雪对他说的——狰血素激活的狂暴不同于肾上腺素狂飙。肾上腺素飙起来的人是疯狗——什么都不怕什么都不想，冲上去咬。但狰血素激活的是感知系统——痛觉消失、力量翻倍的同时，思考会更冷静而非更狂躁，因为你不需要害怕疼痛也不用担心身体反应不够快，脑子里反而更有余裕思考战术。所以狰血素的狂暴不是"疯"，是"锐"——是把你的感知磨到最锋利的那一刻。孤狼叼起一块肉片在舌面上滑了一圈——他闭上眼睛。狰血素在舌尖上释放的灵能脉冲正在顺着三叉神经一路往上——他的听觉在这一刻达到了常人的四倍。他听到了——招待所后面的旧厂房废墟里，有一支渗透小队正在原来的翻砂车间的铁皮屋顶上匍匐，膝头的护膝在生锈的铁皮板上刮出极轻微的沙沙声。那个声音在平时正常听力下完全听不到——但现在他听得清清楚楚，连那个人匍匐时腰带上的钥匙串摩擦铁皮的声音都能数出来。他嘴里的狰肉还在舌面滚着，狰血素不断刷新他神经通路的导电速度——感知不是在使用中消耗，而是在使用中越来越锐。

"旧厂房屋顶有三个人——铁皮屋顶，朝东那间翻砂车间——距离招待所后墙——二十米。"孤狼把最后一口肉咽下去，睁开眼——瞳仁深赤如血。他把匕首在手指之间翻转——刀的冷光在地下室唯一一盏灯泡下划出了一道孤极窄的弧。

小雪放下筷子。她的第三块母狰嫩肉吃得最安静——她一直没有暂停过给骨矛上淬层药，每一口肉嚼完就顺手往矛杆上新上一层薄薄的猎膏，手指的速度稳步增长。她把骨矛竖在地上——矛杆吸饱了七层淬毒膏和狰骨髓淬液，杆子的颜色从骨白变成了淡金，矛尖那半尺长的一片骨刃在灯光下泛起幽幽蓝光。把嘴里最后一口肉咽下去的时候，她抬头看了一眼墙上的钟——从咬第一口到把第三块肉咽完，时间过去了大约七分钟。"我的丹田——热到发烫。"她把手掌平放在小腹上，手心能感到丹田在往外辐射一股均匀而持久的热冲击波，"气血灌过百会——肩井——曲池——涌泉——打通了大周天。持续运行状态大概能撑——两刻钟。"

"也就是地球上的三十分钟。"红叶推推眼镜，把最后一口肉塞嘴里——她的键盘速度此刻已经翻了一倍多，手指在键面上移位的速度看起来几乎像电影快放。她输入时口头吐出一串数据流，因为狂暴让她必须同时用说话来放掉多余的神经过载："我这里大概还剩二十四分钟——按老赵刚才变量的实测数据修正后，你们属于一线战斗型人员，狂暴的效能峰值在前十分钟最高，之后会逐渐衰减。十分钟到二十分钟——效能降至八档；二十分钟到三十分——倾于平。过了三十分钟——突然熄火。"

"也就是说——"孤狼从墙边站直，把匕首往腰里一插，"干得越快越好。"

窗外——碎石路上那三台装甲运兵车的探照灯光在招待所正墙面上交叉扫动，每一道光柱都像一把雪亮的手术刀把黑暗剖开。M249机枪的第一轮长点射已经停了——枪管空转冷却的过程中，你能听到枪管散热片在夜风里被吹得啪啪响。雇佣兵在更换弹药链——第一轮用了弹链式穿甲弹，弹药箱打掉半箱——没有穿深。沈迷那块装甲板挡机枪弹轻轻松松，他们必须换更重的武器——要么是十二点七毫米口径的重机枪，要么是四十毫米口径的榴弹发射器。无论哪一种，正门都不可能撑太久。

"李云——看外面。"红叶说。

她把监控镜头切到碎石路全景。画面里，三辆装甲运兵车成品字排开后，从中间那辆车的车顶舱口探出来一样东西——不是机枪，是一个体型相对更庞大的装置。那玩意的炮盾很厚，短管，炮口有消焰器。红叶放大见——那是一门MK19自动榴弹发射器——四十毫米口径——美军标准反步兵重火力。一分钟打出四十发榴弹，杀伤半径五米。李云盯着那门榴弹发射器看了两秒，脑子里算了一道极其简单的算术题——四十发每分钟乘以十秒等于六到七发榴弹，每发杀伤半径五米，招待所一楼总面积大概一百二十平方米——六发榴弹全覆盖。他们现在有不到六个人扛这一整座楼——不可能凭血肉之躯在四十毫米榴弹的齐射下活下去。

"必须抢在他们开火之前冲出去。"赵铁山把防弹盾牌往手臂上一套——内面的尼龙魔术贴牢牢粘在护臂上，钢板上那三排焊铁的刺面朝外，在探照灯的灯光里泛着一层灰色的寒光。"正面交给我——你们从侧翼压上去。孤狼——老厂房——二十米的铁皮屋顶能轻松走过去，翻进去切后排；小雪——沿江水闸那边，天黑，适合用骨矛狙击；红叶留在地下室监控全局、引路；李云上二楼阳台，狙击视野顶楼比两侧都好。"

"那正面呢？"孤狼问。

赵铁山把防弹盾牌的左下角在地面上敲了一下——咚——那块五十八斤的钢盾在地面上砸出浅坑。"正面我要硬扛正面——不用留人。"

沉默。叶红看着赵铁山的后背——那后背看不出老态，脊骨的每节椎骨的凸起像一串被紧紧锁在一起的钢珠，背阔肌拢起如铁盾。她把目光挪开，手指在键盘上操了一道声控导向路径服送给耳返装置传给所有人——"最外圈压感传感器报告——正面距离不足十五米，正在备弹——重型榴弹重装机枪弹盒正在装——发弹锁打开——"

"上——！"赵铁山在那一瞬踹开了正门上的装甲板。

门板不是向里或向外打开的——是被他从正中间踹裂成两扇碎片飞出去。老赵的铁箍棍别在腰后——他的双手抓着防弹盾牌的两侧把手。他把盾牌平架在胸前——五十八斤的盾面朝外，三排焊刺对准黑暗——然后他一个人冲进了三台装甲运兵车的探照灯光柱里。那一刻碎石路上的雇佣兵看到的是一个绝对不属于这个物理时代的画面——一个黑影顶着钢板从被炸碎的招待所正门里撞出来，脚底的碎石在他脚下被踩成粉末，钢盾在三道探照灯光柱里反出刺目的惨白冷光。然后他在碎石路中央——在距离三台装甲车不到二十米的地方——站稳。一个人。面对三辆装甲车、至少四十个雇佣兵、三挺M249、一门MK19自动榴弹发射器。

他没有喊任何口号。他只是用左手拎着那块五十八斤的防弹盾牌，慢慢地平举到身前——盾面上那三排焊铁刺在探照灯惨白的光芒里，看着像是用骨头拼出来的一副牙齿。

然后他迈出了第一步——

碎石在他脚底下爆开的声响，比他身后招待所正在塌碎的门框残骸更沉。

此时李云踏上了二楼阳台的地面——二楼阳台原是招待所总经理房间的外露台，长五米半、宽一米六，正好能架一杆狙而不易被榴弹正面炸到。她把狙击枪架在阳石头护栏的V形豁口——架好——开镜——红点消线点在碎石路上排着一列的火光——然后是倚着突击步枪正架标准射击位的第一切兵。

"老赵——给他们排头一个见面礼。"李云在耳返里轻声道。

赵铁山听见了。他把防弹盾牌从平举变成斜倾——盾顶前压——整个身体重心下沉——双腿一蹬——

一声闷响。五十八斤全钢防弹盾以四十七公里每时的冲刺速度正面撞在第一辆装甲运兵车的车头部钢板上——侧面的焊铁刺嵌进钢板上原有的折线——勾住——往上一掀——轰——第一辆装甲车的车头钢板被撕下半个，车内的发动机和传动箱全暴露了——水箱爆了——一股滚烫的淡绿色防冻液喷了老赵一脸。他的帽檐上挂着几滴亮绿色的防冻液，在惨白探照灯光的光痕里闪。他的眼睛——深赤如烧透的炭火，在防冻液蒸汽形成的浅绿色雾气里格外醒目。车内的司机和副驾一侧的机枪手愣了一帧——然后他们就看到了盾牌上升。

老赵举盾砸——盾牌底部那根从沈迷装甲车拆下来的钢条从钢板下竖线锚钉上崩开——然后在末端弯了一个角度——末锋向下砍——把驾驶舱的架栏砍开了——司机视线被击断。老赵腾出一只手抽铁箍棍——抽棍挥——棍头打在车顶四十毫米榴弹发射器的供弹口上——那滚齿供弹口被棍砸扁——卡弹——自动榴弹打出两发哑弹——弹不死。

——然后他身后，机枪响了。

但不是佣工们的——是孤狼在废弃老厂房铁皮屋顶上缴的佣兵前哨的M249。他蹲在屋顶，左手托弹链——右手扣住握铁，枪口朝下对准厂房后面正在架设迫击炮的迫击炮组的切兵。扳机扣到底——长连射。枪声在旧厂房的铁皮屋顶上回荡，像从天而降的滚动雷霆——铁皮屋顶在连续冲击振动下嗡嗡脆响，迫击炮组三个人在同一瞬被六颗连发贯穿——血把迫击炮的底座钢板喷成了一副深红的涂鸦。

小雪隐在沿江水闸的废弃闸门后面——骨矛置到手——丹田热到场——猛地振腕——掷矛——空中骨矛从她的手臂脱手时角度巧妙飞出——旋转速度——划破夜空的哨气喘——对准碎石路队伍最右侧那个刚端起来的MK19备用弹药箱的佣兵——穿透胸背——贯穿。骨矛扎进他身后的碎石路——钉在地上，矛杆上接连挂住第二人和第三人——第二个被矛穿右肩——第三人刺左肋下一缝——骨矛穿透两层凯夫拉——但这还没完。

她掷第二根——骨矛取自狰的脊椎中段，淬毒加满，杆身以六十度斜角射入碎石路队伍阵形右侧的间隙——钉在碎石中弹跳——横飞扫中第四个人的腿——

连穿三——骨矛从第三个的身上弹落地钉死地时——五人——倒下。佣兵阵角失效。


与此同时，招待所正门前——

赵铁山举着防弹盾牌，踩着碎石，挪后半步；然后突然把盾牌往碎石地上一杵——盾底那个故意打磨的钢条尖稳稳穿上碎石——成了盾墙。

"该李云了。"他低声说。
